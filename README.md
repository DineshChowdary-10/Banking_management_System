# Bank Management System

A **console-based Bank Management System** developed using **Core Java, Object-Oriented Programming (OOP), JDBC, and MySQL**.

The application allows users to perform basic banking operations through a command-line interface while storing customer, account, and transaction data in a MySQL database.

## Features

- Customer creation
- Bank account creation
- Deposit money
- Withdraw money
- Fund transfer between accounts
- Balance checking
- Transaction history
- Customer and account management
- Insufficient balance validation
- Database transaction handling using commit and rollback
